CÁCH LÀM TRÊN GITHUB
--------------------
Với file cần ghi đè:
1. Mở đúng file trong repo GitHub.
2. Bấm biểu tượng Edit (bút chì).
3. Ctrl+A toàn bộ nội dung cũ.
4. Dán toàn bộ nội dung file cùng tên trong gói V3.3.
5. Commit changes.

Với file mới:
1. Chọn Add file > Create new file.
2. Gõ đúng đường dẫn, ví dụ: src/sentence-learning.js
3. Dán nội dung file tương ứng.
4. Commit changes.

Với data/content:
- Nếu chưa có thư mục content, GitHub tự tạo khi bạn nhập tên file:
  data/content/sentences-v1-core-200.json
  data/content/dialogues-v1-core-30.json
